# Contract Review Assistant — demo web app

Next.js App Router. **All findings are real model output**, generated by the
fine-tuned three-task LoRA adapter (Llama-3.1-8B-Instruct) and archived during
evaluation. Nothing on these screens is mocked.

## Run

```
module load nodejs/24.15.0
npm install
npm run dev          # http://localhost:3000
```

## Where the data comes from

`data/reviews.json` is produced by `../build_demo_data.py`, which reads the
archived predictions at `/scratch/ibi761/legalai/v2_results/raw__llama_3task.jsonl`
and locates each quoted span in the source contract using the same routine that
round-tripped 745/745 gold spans during evaluation. Regenerate with:

```
python ../build_demo_data.py
```

## Two reviews, deliberately

The two model tasks cover different document populations:

* ContractNLI's 17 playbook positions are NDA-specific (Receiving Party,
  Confidential Information).
* CUAD's 18 clause categories are commercial-agreement-specific (Exclusivity,
  Revenue Sharing, License Grant).

One document cannot honestly demonstrate both. The app shows whichever applies
and states why the other tab is empty, rather than presenting a half-empty
screen as a result.

## What is real vs stubbed

| screen | state |
|---|---|
| Dashboard | real |
| New review | real form; upload selects one of the two analysed contracts |
| Processing | real stage names and counts; timings mimic measured throughput |
| Workspace, both tabs | real |
| Finding card, click-to-jump highlight | real, driven by character offsets |
| Accept / Flag / Dismiss | real, local state only |
| Export | stubbed, outputs specified |
| Playbook editor | read-only |

## Honesty features

* Contradiction precision is 0.670 on dev, so roughly one flagged position in
  three is wrong. The finding card says so.
* Clause inventory uses **Found / Not detected**, never "absent" — the model's
  absence claim is a prediction.
* "Not addressed" is amber, not grey: silence in a contract is commercial
  exposure, and it is the model's hardest class.
